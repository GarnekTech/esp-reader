# esp-reader
Мини шпаргалка (ридер) на ESP32 S3 Supermini
# Детали
• **ESP32 S3 Supermini**

• **Литиевая батарейка**

• **Плата зарядки TP4056 (желательно с защитой)**

• **3 тактовые кнопки**

• **Oled i2c дисплей**

# Схема подключения

| Откуда | Пин | Куда | Пин |
| :--- | :--- | :--- | :--- |
| **АКБ** | + | **TP4056** | B+ |
| **АКБ** | - | **TP4056** | B- |
| **TP4056** | OUT+ | **ESP32** | 5V |
| **TP4056** | OUT- | **ESP32** | GND |
| **OLED** | GND | **ESP32** | GND |
| **OLED** | VCC | **ESP32** | 3V3 |
| **OLED** | SDA | **ESP32** | GPIO 8 |
| **OLED** | SCL | **ESP32** | GPIO 9 |
| **Кнопка ВВЕРХ** | Пин 1 | **ESP32** | GND |
| **Кнопка ВВЕРХ** | Диагональ | **ESP32** | GPIO 5 |
| **Кнопка ВЫБОР** | Пин 1 | **ESP32** | GND |
| **Кнопка ВЫБОР** | Диагональ | **ESP32** | GPIO 6 |
| **Кнопка ВНИЗ** | Пин 1 | **ESP32** | GND |
| **Кнопка ВНИЗ** | Диагональ | **ESP32** | GPIO 7 |

# Как закидывать файлы?

• **Скачиваем плагин Arduino LittleFS Upload**

• **По пути** C:\Users\Ваш Юзер\.arduinoIDE **создаем папку** "plugins" **и закидываем туда наш плагин**

• **В папке с проектом создаем папку "data" и закидываем туда наш текст в формате UTF-8**

• **В Arduino IDE нажимаем** Ctrl + Shift + P **и пишем** "LittleFS" **нажимаем** "Upload LittleFS to Pico/ESP8266/ESP32" **ждем**

• **Готово**
